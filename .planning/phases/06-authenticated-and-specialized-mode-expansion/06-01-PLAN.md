<threat_model>
T-CCM-01: A CCM implementation can encrypt/decrypt bytes while computing the wrong authentication tag.
Mitigation: Add fixed ciphertext/tag vectors and wrong-tag rejection checks.

T-CCM-02: Benchmark rows can hide AEAD parameters and make CCM look like generic streaming encryption.
Mitigation: Document nonce length, tag length, AAD scope, and payload-size scope in docs and mode notes.

T-CCM-03: Adding AEAD dispatch can regress existing GCM tag handling or existing confidentiality modes.
Mitigation: Preserve existing mode list entries and KAT coverage; use source checks that include old and new modes.
</threat_model>
