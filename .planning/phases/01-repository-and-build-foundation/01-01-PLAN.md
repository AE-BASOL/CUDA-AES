<threat_model>
Phase 1 is build infrastructure, not runtime cryptography. Primary risks are supply-chain/build integrity risks:
- A malicious or accidental local absolute path could link the wrong OpenSSL build.
- A fake host compiler path can hide real configure failures.
- Optional profiling tooling must not execute unexpected binaries by default.

Mitigations in this plan:
- Use CMake package discovery/imported targets for OpenSSL.
- Remove private absolute paths from source-controlled build logic.
- Make optional tools opt-in through cache variables and existence checks.
</threat_model>
