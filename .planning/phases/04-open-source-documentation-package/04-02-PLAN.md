<threat_model>
Governance risks:
- License selection is a legal commitment.
- Security policy can invite production-library vulnerability reports that are out of scope.
- Issue templates can encourage unsupported performance claims.

Mitigations:
- Use a conventional permissive default only if no license exists, and document it as a maintainer-review item.
- Make SECURITY.md clear that this is benchmark/research software.
- Ask for reproducible commands, raw artifacts, correctness status, and environment details in contribution templates.
</threat_model>
