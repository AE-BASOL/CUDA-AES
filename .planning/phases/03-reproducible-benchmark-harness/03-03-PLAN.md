<threat_model>
Documentation risks:
- Methodology copy can overclaim benchmark credibility before runtime verification succeeds.
- README examples can imply that kernel-only throughput is full application throughput.
- Documentation can drift from the actual flags and summary script.

Mitigations:
- Phrase benchmark results as reproducible measurements, not unsupported fastest claims.
- Put timing-scope caveats next to commands and summary output.
- Verify documented commands against source strings and, where possible, runtime behavior.
- Record environment-limited verification separately from source-level plan completion.
</threat_model>
