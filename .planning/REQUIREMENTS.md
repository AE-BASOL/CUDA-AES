# Milestone v2.0 Requirements

### Global Packaging (PKG)
- [ ] **PKG-01**: Implement global packaging and distribution (e.g., via `npx` or npm module) to allow anyone to run the benchmark easily.
- [ ] **PKG-02**: Add installation and usage instructions for the global package to the README.

### Benchmarking (BENCH)
- [ ] **BENCH-10**: Implement a CPU vs GPU benchmark comparison framework using OpenSSL for CPU reference.
- [ ] **BENCH-11**: Generate standardized results tables comparing multiple GPU models and CPU performance.

### Research & Expansion (RES)
- [ ] **RES-01**: Research the GPU cryptography ecosystem to evaluate competitor solutions and mode completeness.
- [ ] **RES-02**: Propose and document the addition of new features based on ecosystem research.

### Maintenance & Hygiene (MAINT)
- [ ] **MAINT-05**: Delete and resolve all stale feature branches from the repository to clean up history.
- [ ] **MAINT-06**: Verify that GitHub repository settings and CI/CD pipelines align with best practices for a highly-starred open-source project.
