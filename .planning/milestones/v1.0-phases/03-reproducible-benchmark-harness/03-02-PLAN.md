<threat_model>
Benchmark summary risks:
- A summary script can hide raw-data problems if it silently drops invalid rows.
- Aggregating kernel-only and end-to-end timing together produces misleading throughput claims.
- Unsupported CSV assumptions can break as soon as the raw schema evolves.

Mitigations:
- Validate required input fields and fail with clear errors when rows are malformed.
- Group or filter by `timing_scope`.
- Keep the summary schema simple and documented.
- Preserve raw artifacts; summaries are derived outputs, not the source of truth.
</threat_model>
