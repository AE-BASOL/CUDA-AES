<threat_model>
CFB/OFB risks:
- CFB segment-size ambiguity can make tests and docs misleading.
- OFB encryption and decryption can diverge accidentally even though both use the same keystream XOR.
- Feedback-mode benchmark rows can be mistaken for authentication or CTR-like parallelism.

Mitigations:
- Lock Phase 5 to CFB-128 and state that decision in tests and docs.
- Reuse a single OFB transform path where practical.
- Add deterministic vectors and documentation before accepting benchmark claims.
</threat_model>
