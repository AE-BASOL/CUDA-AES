<threat_model>
CBC risks:
- Random round-trip checks can hide wrong IV chaining or byte ordering.
- CBC encryption dependency can be misrepresented as highly parallel GPU throughput.
- Adding mode branches can break existing ECB/CTR/GCM paths.

Mitigations:
- Use fixed multi-block CBC known-answer vectors for AES-128 and AES-256.
- Keep benchmark documentation explicit about chained-mode limitations.
- Preserve existing mode dispatch and add source-level checks for old and new modes.
</threat_model>
