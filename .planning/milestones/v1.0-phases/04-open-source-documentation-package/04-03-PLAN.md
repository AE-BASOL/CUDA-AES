- Matrix can imply implemented coverage for future modes.
- GMAC/CMAC can be confused with bulk encryption modes.
- Legacy code can be mistaken for current canonical implementation.

Mitigations:
- Use explicit implementation/test/benchmark/documentation status columns.
- Separate encryption modes from MAC/authentication-only coverage.
- State that top-level source is canonical and legacy folder is provenance/reference unless later scoped.
</threat_model>
