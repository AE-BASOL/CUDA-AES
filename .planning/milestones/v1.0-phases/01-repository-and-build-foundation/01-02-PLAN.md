<threat_model>
Repository hygiene affects supply-chain clarity:
- Generated binaries or IDE files can hide accidental local state in source review.
- Ambiguous duplicate source trees can cause contributors to patch the wrong implementation.

Mitigations in this plan:
- Inspect tracked files before removing anything.
- Remove only tracked generated/IDE artifacts if present.
- Document canonical top-level source boundary and defer broader source moves.
</threat_model>
