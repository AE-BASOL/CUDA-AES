<threat_model>
T-KW-01: AES-KW/AES-KWP unwrap can return corrupted key material if integrity checks are not enforced.
Mitigation: Add unwrap failure tests for tampered wrapped input.

T-KW-02: KWP padding can be implemented with incorrect message length recovery.
Mitigation: Add KWP vectors with non-64-bit-multiple plaintext key data and verify unwrap length/content.

T-KW-03: Benchmark rows can imply bulk encryption throughput.
Mitigation: Label and document rows as key-wrap workloads with payload-size/batch assumptions.
</threat_model>
